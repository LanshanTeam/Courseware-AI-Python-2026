# Courseware-AI-Python-2026

蓝山工作室 Python 方向 2026-2027 年秋季课件

p.s.在学习期间，请大家一定快速熟悉《高等数学》各种导数偏导的计算，梯度的计算。《线性代数》矩阵的各种变化与运算。这个不在授课内容中，但对大家在学习过程中有很大帮助。无数学无人工智能。

### 课程安排

| 序号 | 模块                                                 | 内容说明                                                     | 主讲人 |
| ---- | ---------------------------------------------------- | ------------------------------------------------------------ | ------ |
| 01   | Python 核心语法与数据结构                            | Python 项目的基本框架。数据类型、变量与常量，基本语句（if、for、range），函数与模块，list 与 dict 等常用数据结构，类型注解 | 钟焯耀 |
| 02   | Python 包管理、面向对象与工程基础                    | pip / conda / uv 包管理与依赖声明，虚拟环境与规范的项目工程结构。类与对象、封装继承多态，文件与异常处理 | 钟焯耀 |
| 03   | 网络编程与并发基础                                   | 从 socket 编程起手理解什么是网络、请求与 http 协议。多进程、多线程与 GIL，asyncio 异步编程 | 周远洋 |
| 04   | PostgreSQL 关系型数据库与 SQL 实践                   | PostgreSQL 安装与建库建表。增删改查，条件查询、聚合与多表连接，用 Python 连接与 SQLAlchemy ORM 入门 | 胡桐   |
| 05   | FastAPI 后端开发与 RESTful API 接口                  | FastAPI 组件介绍与路由、请求参数。Pydantic 数据校验，依赖注入与中间件，自动生成 API 文档 | 刘哲宇 |
| 06   | ChromaDB 向量数据库与 Embedding 基础                 | Embedding 与余弦相似度、向量检索原理。ChromaDB 的 Collection 概念，向量增删改查与元数据过滤 | 齐倩瑞 |
| 07   | 大模型基础与 API 调用模型                            | 大模型能力边界与 Token、上下文窗口。模型选型，OpenAI 兼容 API 调用，SSE 流式输出与接口封装 | 刘哲宇 |
| 08   | 提示词工程与聊天机器人实战                           | Prompt 结构与提示词工程技巧，少样本与思维链。多轮对话上下文管理，对话记忆存储，聊天机器人实战 | 齐倩瑞 |
| 09   | 能力封装为 API 与 Agent 初探                         | 接口设计规范与统一响应。Function Calling 与 Agent 执行循环，构建能查库、检索、调用工具的小 Agent | 胡桐   |
